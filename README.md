Demo displaying the simulation of particles in combination with position based dynamics to get rigidbodies to interact with the particle cells. Trying to replicate the behaviour of Noita's physics engine, however this approach may result in better rigidbody/particle interaction as Noita's system uses Box2D for simulations however I've found that using Position Based Dynamics actually is simpler to implement and produces more emergent behaviour such as boat like shapes floating on water!
